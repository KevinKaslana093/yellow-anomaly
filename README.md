# 黄色生物 · 屋顶乱斗

奶蛙、袋鼠、牛来的 **3D 近身乱斗游戏**。空手三段连击，抢地图武器，把对手打出屋顶。单人对抗五名彼此敌对的电脑选手，无需安装。

**[在线试玩](https://kevinkaslana093.github.io/yellow-anomaly/?v=3)** · **[下载离线版](https://github.com/KevinKaslana093/yellow-anomaly/releases/latest)**

## v3 玩法

每人两条命，受击积累伤害百分比：伤害越高，受到的击退越强。掉出边缘损失一条命并复活，最后留下者获胜。55 秒后屋顶逐渐缩小；180 秒仍有多人时，依次比较剩余命数、较低伤害和击飞数。

- 徒手：左右拳接第三段踢击，按住攻击可以连打，近身辅助朝向对手。
- 棒球棍：距离长；平底锅：出手快；重锤：前摇长、击退强。
- 武器有耐久，可以拾取、交换、投掷；重击可能打落武器，损坏后回到徒手。
- 奶蛙肚皮震退，袋鼠飞身双踢，牛来蛮牛冲撞。牛来较重，袋鼠移动较快。
- 电脑选手会抢武器、攻击彼此、闪避、使用绝招。红色预警表示即将挥击。
- 小地图显示对手、武器及屋顶边缘。青色标记是玩家，红色是对手。

## 操作

| 动作 | 电脑 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 徒手或武器攻击 | J / 鼠标左键，可按住 |
| 闪避 | 空格 / K |
| 拾取、交换武器 | E |
| 投掷手中武器 | Q |
| 角色绝招 | F |
| 暂停 | Esc |

手机：左侧摇杆移动，右侧攻击、闪避、拾取、投掷、绝招按钮。设置支持手动选择操作方式、声音、节奏音乐、后期与减少动态效果；失焦自动暂停。最高分与设置只保存在当前浏览器。角色在开局前选择，本版没有联机功能。

## 渲染与运行

实时 Three.js 模型、武器与跑动/挥击/受击/坠落动画，动态阴影，HDR 辉光、调色、抗锯齿与暗角。屋顶缩小时镜头靠近。关闭后期可以降低渲染开销。不支持 WebGL 时提供基础平面兼容视图。

使用任意静态服务器托管 public 目录，例如：

~~~sh
python -m http.server 8765 --directory public
npm test
npm run build
~~~

构建输出 dist/yellow-anomaly-brawl.html，所有资源内嵌，可离线打开。推送 main 后 GitHub Actions 运行测试并部署 public 到 GitHub Pages。

14 项确定性测试覆盖手动连击、前摇和命中弧、击退、闪避、武器耐久/投掷/交换、复活与胜负、绝招、收缩与完整电脑比赛。浏览器检查覆盖桌面 1440×900、手机 390×844、横屏 844×390、窄屏 360×640，多点触控、暂停/重开、设置保存和胜败流程。
