# 黄色生物 · 失控现场

奶蛙、袋鼠、牛来的 **3D 生存肉鸽动作游戏**。纯浏览器运行，无外部服务依赖。

v2.0 将战斗升级为实时 3D：三名角色均由立体模型绘制，可转身、跑动和跳跃；斜俯视透视镜头、实体竞技场、障碍物、立体敌人和 Boss、动态投影。后期包括 HDR 辉光、色调映射、边缘抗锯齿与轻微暗角。手机采用较低渲染分辨率与四分之一尺寸辉光；设置中可关闭后期。角色为保留梗图关键特征的风格化建模，首页仍使用重绘形象图。

**[在线试玩](https://kevinkaslana093.github.io/yellow-anomaly/)** · **[下载离线版](https://github.com/KevinKaslana093/yellow-anomaly/releases/latest)**

## 玩法

自动攻击最近敌人，走位躲避攻击，收集绿色能量升级。150 秒时 Boss 清场者登场，击败它获胜；240 秒后封锁竞技场。

- WASD / 方向键：移动
- 1 / 2 / 3 或 Q：切换角色
- 空格：角色技能（奶蛙音波震荡、袋鼠极地冲刺、牛来重砸）
- E：三黄合击，击破敌人充能
- Esc：暂停 / 继续
- 手机：设置切到手机模式，左侧摇杆移动，右侧技能，点击头像切换
- 场内四座圆柱是实体障碍，会阻挡角色、敌人和子弹。

角色共享生命和强化，各自技能冷却独立。红色圆圈和冲撞线是危险预警，绿色十字是恢复补给。设置支持声音、音乐、减少动态效果和操作方式切换。最高分和设置只保存在当前浏览器。

## 本地运行与验证

`python -m http.server 8765 --directory public` 后在浏览器打开本地地址。

`npm test` 运行固定随机种子的战斗测试。

`npm run build` 输出包含所有资源的离线单文件 HTML，可直接双击打开。

推送到 `main` 会自动运行战斗测试并发布 GitHub Pages。发布目录为 `public/`。浏览器验收覆盖 1440×900 电脑、390×844 竖屏、844×390 横屏及 360×640 窄屏，已验证多点触控、升级、暂停、胜败和重开流程。

## 角色美术

角色根据公开梗图通过内置 imagegen 工具生成，为游戏重绘形象。保留奶蛙绿眼圆肚、袋鼠长耳棕鼻、牛来黄毛牛角紫嘴的特征。

参考出处：[3DM 角色介绍及图片](https://www.3dmgame.com/original/3746364.html)。游戏没有使用原视频音频，战斗声与节奏音乐为程序合成。

图像资产：`public/assets/trio.png`。生成提示词：`ART-PROMPT.txt`。

3D 模型、场景、动画和后期：`public/arena3d.js`。Three.js 0.160.1 随游戏打包，不依赖 CDN，MIT 许可证见 `public/vendor/three-LICENSE.txt`。不支持 WebGL 的浏览器保留兼容的平面视图。
